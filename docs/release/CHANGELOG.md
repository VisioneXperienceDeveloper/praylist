# Praylist 변경사항

사용자에게 보이는 주요 변경사항을 앱 버전별로 간략히 기록합니다. 버전 증가는 [버전 관리 규칙](../DEVELOPMENT.md#버전-관리)에 따릅니다.

## 1.3.0 (개발 중)

- 홈 화면 소형·중형·대형 위젯을 추가했습니다. 위젯별로 오늘의 기도, 새 pray 작성, 선택한 pray, 카테고리 목록을 선택할 수 있습니다.
- 위젯 설정에서 `위젯 타입`을 먼저 고르고 타입에 필요한 하위 옵션만 표시합니다. 카테고리와 pray 선택기는 현재 언어와 저장된 실제 이름을 사용합니다.
- 제목 공유는 기본으로 꺼져 있으며 앱의 공유 허용과 각 위젯의 제목 표시 설정을 모두 켜야 제목을 표시합니다. 메모는 공유하지 않습니다.
- 삭제·이동·달성된 대상과 가득 찬 항목을 확인하고, 위젯을 열어도 기도·달성 기록을 자동 생성하지 않습니다.

## 1.2.3

- 한국어 온보딩의 pray 표기를 통일했습니다.
- iOS 27의 키보드·달력 접근성 형식에 맞춰 UI 테스트를 보완하고, 알림 수신 테스트가 이전 온보딩 상태의 영향을 받지 않도록 수정했습니다.
- 1.2.0~1.2.2의 변경사항을 포함한 빌드 7을 2026-09-29에 App Store 심사에 제출했습니다.

## 1.2.2

- 노트 화면에서 옆으로 넘기라는 안내 문구를 제거했습니다.

## 1.2.1

- 오늘의 기도를 마친 뒤 목록으로 돌아가는 버튼 문구를 `list로 돌아가기`로 변경했습니다.

## 1.2.0

- 이어서 진행할 수 있는 온보딩과 추천 항목·알림 설정 단계를 추가했습니다.
- 언어 변경 후 추천 항목이 선택한 언어로 갱신되도록 수정하고, 항목 설명을 100자로 제한했습니다.
- 시스템·라이트·다크 테마 선택을 추가하고 앱 아이콘과 브랜드 표시를 통일했습니다.
- 화면에 표시하는 앱 버전을 Xcode 빌드 설정에서 가져오도록 연결했습니다.

> 아래 1.1.4·1.1.0은 별도 기능 브랜치의 개발 이력이며, 해당 브랜치의 변경사항은 1.2.3 제출 빌드에 포함되지 않습니다.

## 1.1.4 (별도 개발 브랜치)

- 홈 화면 및 잠금 화면 위젯을 추가했습니다.
- 위젯 탭이 개인정보 보호 설정에 맞춰 오늘의 기도 화면으로 이동하도록 개선했습니다.

## 1.1.0 (별도 개발 브랜치)

- 오늘의 기도 흐름과 완료 상태·완료 안내를 추가했습니다.
- 앱 테마 설정을 추가했습니다.

## 1.0.0

- Pray 항목과 기록을 관리하는 기본 노트 기능으로 첫 버전을 출시했습니다.
- 오늘의 기도, 기도 달력, 로컬 알림, 한국어·영어, 기기 내 저장과 JSON 백업을 포함했습니다.
