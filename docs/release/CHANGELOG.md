# Praylist 변경사항

사용자에게 보이는 주요 변경사항을 앱 버전별로 간략히 기록합니다. 버전 증가는 [버전 관리 규칙](../DEVELOPMENT.md#버전-관리)에 따릅니다.

## 1.2.1

- 오늘의 기도를 마친 뒤 목록으로 돌아가는 버튼 문구를 `list로 돌아가기`로 변경했습니다.

## 1.2.2

- 노트 화면에서 옆으로 넘기라는 안내 문구를 제거했습니다.

## 1.2.0

- 이어서 진행할 수 있는 온보딩과 추천 항목·알림 설정 단계를 추가했습니다.
- 언어 변경 후 추천 항목이 선택한 언어로 갱신되도록 수정하고, 항목 설명을 100자로 제한했습니다.
- 시스템·라이트·다크 테마 선택을 추가하고 앱 아이콘과 브랜드 표시를 통일했습니다.
- 화면에 표시하는 앱 버전을 Xcode 빌드 설정에서 가져오도록 연결했습니다.

## 1.1.4

- 홈 화면 및 잠금 화면 위젯을 추가했습니다.
- 위젯 탭이 개인정보 보호 설정에 맞춰 오늘의 기도 화면으로 이동하도록 개선했습니다.

## 1.1.0

- 오늘의 기도 흐름과 완료 상태·완료 안내를 추가했습니다.
- 앱 테마 설정을 추가했습니다.

## 1.0.0

- Pray 항목과 기록을 관리하는 기본 노트 기능으로 첫 버전을 출시했습니다.
- 오늘의 기도, 기도 달력, 로컬 알림, 한국어·영어, 기기 내 저장과 JSON 백업을 포함했습니다.
