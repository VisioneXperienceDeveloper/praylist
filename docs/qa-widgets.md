# 홈 화면 위젯 구현과 검증

## 구현

- 브랜치: `feature/home-screen-widgets`, main `2a97d54`에서 시작.
- 버전: `1.3.0 (12)`. 기존 기능을 유지하는 위젯 추가이므로 MINOR 증가.
- `PraylistWidget/`: AppIntentConfiguration으로 위젯 타입을 먼저 고르고, 타입에 필요한 카테고리/pray와 제목 표시만 이어서 설정한다. small/medium/large 지원.
- `Praylist/Shared/`: 최소 스냅샷과 URL 형식. 개인 JSON, 메모, 기도 이력은 위젯에 전달하지 않음.
- `PrayStore`: 원자 저장 성공 이후에만 스냅샷 발행. 새 설치, 복원, 언어 변경, 앱 활성화에서도 현재 저장 상태로 갱신.
- `WidgetRouter`와 `NotebookView`: URL 검증 후 기존 기도 화면/인라인 입력/카테고리 페이지로 이동. 삭제·이동·달성된 pray는 안내 후 노트로 이동.
- 선택한 pray와 카테고리 목록은 카테고리명을 항상 표시한다. 위젯별 제목 표시 ON이면 pray명도 표시하고 OFF이면 pray명과 페이지 컨트롤을 숨기고 잠금 아이콘과 비공개 안내를 표시한다. 앱 전역의 추가 허용 단계는 제거했다. App Group에는 선택기용 ID·이름·달성 여부와 알림 시각·활성 여부·발행일의 기도 완료 날짜만 공유하며 메모와 전체 기도 이력은 없다.
- 선택한 pray는 카테고리 선택 후 그 안의 미달성 pray만 제안한다. 다른 카테고리에 속한 오래된 선택은 표시하거나 열지 않는다.
- 소형(2×2)은 오늘의 기도·새 기도 두 타입만 선택할 수 있다. 새 기도에서만 카테고리를 선택한다. 중형(4×2)은 1개씩, 대형(4×4)은 5개씩 개별 pray 링크를 표시한다. 페이지 점 AppIntent 버튼은 앱을 열거나 PrayData를 쓰지 않고 페이지만 갱신한다. WidgetKit에서 내부 가로 스와이프는 지원하지 않는다. 동일 카테고리·동일 크기의 목록 위젯끼리는 현재 페이지를 공유하며 크기와 카테고리가 다르면 독립적으로 유지한다. 삭제 후 페이지 범위를 벗어나면 마지막 유효 페이지로 보정한다.
- 지원 대상은 홈 화면. accessory family는 제공하지 않으며 StandBy는 비선호 위치로 설정. OS가 다른 표면에 배치하는 것을 완전히 차단한다고 보장하지 않음.

- 대형 위젯은 카테고리명 title2, pray명 title3로 확대했다. pray 목록은 본문 영역의 수직 중앙에 배치하고 그 아래에 페이지 점 컨트롤을 표시하며, 현재 페이지는 진한 점으로 표시한다. 각 점을 누르면 해당 페이지로 이동한다.
- 상단은 카테고리명 왼쪽·앱 이름 없이 로고만 오른쪽의 한 줄로 배치한다. 대형 위젯에서 제목 아래 추가 여백은 10pt, pray 행 사이는 16pt로 늘렸다.

- 오른쪽 맨 아래에는 항상 알람 아이콘과 앱 리마인더 시각만 표시한다. 예정 시각 전은 회색, 시각 이후는 은은한 빛 효과, 오늘 기도 완료 후는 검정색이다. 다크 모드에서는 완료 글자 뒤에 밝은 배경을 둔다. 알림 OFF도 같은 알람 아이콘을 쓰고 회색으로 표시한다.
- 타임라인에 기도 시각과 자정 전환을 미리 넣어 다음 날 완료 표시가 초기화된다. 앱에서 설정·완료 기록을 저장하면 스냅샷과 타임라인을 다시 발행한다. 시스템 표시 시점에는 지연이 있을 수 있다.

## 사용 방법

홈 화면을 길게 눌러 **편집 → 위젯 추가 → Praylist**에서 크기를 고릅니다. 배치한 위젯을 길게 눌러 **위젯 편집**에서 위젯 타입을 고르면 필요한 하위 옵션만 나타납니다.

선택한 pray 타입에서는 **카테고리 → pray** 순서로 선택합니다. 선택한 pray와 카테고리 목록 타입에서 **제목 표시 ON**이면 카테고리명과 pray명, **OFF**이면 카테고리명과 잠금 아이콘·비공개 안내가 보입니다. 카테고리 목록은 제목 표시 ON에서 페이지 점 버튼으로 페이지를 넘길 수 있습니다. 메모는 표시하지 않습니다. 시스템 타임라인 갱신에는 지연이 있을 수 있습니다.
