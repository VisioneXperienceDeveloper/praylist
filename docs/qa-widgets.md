# 홈 화면 위젯 구현과 검증

## 구현

- 브랜치: `feature/home-screen-widgets`, main `2a97d54`에서 시작.
- 버전: `1.3.0 (8)`. 기존 기능을 유지하는 위젯 추가이므로 MINOR 증가.
- `PraylistWidget/`: AppIntentConfiguration으로 위젯 타입을 먼저 고르고, 타입에 필요한 카테고리/pray와 제목 표시만 이어서 설정한다. small/medium/large 지원.
- `Praylist/Shared/`: 최소 스냅샷과 URL 형식. 개인 JSON, 메모, 기도 이력은 위젯에 전달하지 않음.
- `PrayStore`: 원자 저장 성공 이후에만 스냅샷 발행. 새 설치, 복원, 언어 변경, 앱 활성화에서도 현재 저장 상태로 갱신.
- `WidgetRouter`와 `NotebookView`: URL 검증 후 기존 기도 화면/인라인 입력/카테고리 페이지로 이동. 삭제·이동·달성된 pray는 안내 후 노트로 이동.
- 기본 숨김. 앱 설정에서 제목 공유를 허용하면 App Group에 제목을 포함. 위젯별 제목 표시도 켜야 렌더링. 권한 철회 시 공유 플래그를 먼저 끄고 스냅샷을 갱신.
- 소형 위젯은 하나의 진입점, 중형/대형 카테고리 목록은 개별 pray 링크 제공. 목록 최대 표시 수는 1/2/6개이며 전체 내용은 앱에서 확인.
- 지원 대상은 홈 화면. accessory family는 제공하지 않으며 StandBy는 비선호 위치로 설정. OS가 다른 표면에 배치하는 것을 완전히 차단한다고 보장하지 않음.

## 검증 기록

- iPhone 18 Pro / iOS 27: 앱과 위젯 확장 빌드·설치 성공.
- 위젯 단위 테스트 9개 + 실제 URL UI 테스트 1개 통과.
- 네 목적지, 새 pray 정확히 1개 저장, 무효 대상 안내, 제목 기본 비공개, 메모 미포함, 저장 실패 시 미발행 확인.
- 전체 회귀 테스트 41개 통과, 3개는 기존 조건부 건너뜀.
- 실기기 서명은 Apple 팀에 등록된 기기와 개발 프로비저닝 프로파일이 없어 완료하지 못했습니다. 실제 기기에서 확인하지 않은 표면은 검증 완료로 간주하지 않습니다.

## 사용 방법

홈 화면을 길게 눌러 **편집 → 위젯 추가 → Praylist**에서 크기를 고릅니다. 배치한 위젯을 길게 눌러 **위젯 편집**에서 위젯 타입을 고르면 필요한 하위 옵션만 나타납니다.

제목을 보고 싶다면 앱 **설정 → 홈 화면 위젯 → 위젯에 제목 공유 허용**을 켠 뒤 해당 위젯의 **제목 표시**를 켭니다. 위젯 편집의 카테고리와 pray 선택기는 앱 언어와 저장된 실제 이름을 사용하며, 제목 공유를 끄면 홈 화면 렌더링에서만 제목을 순번으로 가립니다. 메모는 표시하지 않습니다. 시스템 타임라인 갱신에는 지연이 있을 수 있습니다.
