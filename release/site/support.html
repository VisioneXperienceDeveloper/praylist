Praylist 사용 안내

pray를 담고, 매일 기도하다.

Praylist는 나의 pray를 항목별로 적고 기도와 응답의 순간을 기록하는 iPhone 앱입니다.

첫 pray는 어떻게 만드나요?

처음 앱을 열면 원하는 항목을 고르고 첫 pray를 적습니다. 이후에는 노트의 빈 줄을 눌러 내용을 입력하고 키보드의 완료를 누르면 저장됩니다. 기존 pray의 글씨를 누르면 같은 자리에서 바로 수정할 수 있습니다.

한 항목에 몇 개까지 담을 수 있나요?

각 항목에는 응답된 pray를 포함해 최대 10개를 보관할 수 있습니다. 자리가 모두 차면 새 항목을 만들거나 필요 없는 pray를 삭제해 자리를 비워주세요. 삭제 전에 백업을 내보내면 기존 기록을 별도로 보관할 수 있습니다.

항목과 순서를 바꾸고 싶어요.

설정 → 항목 관리에서 항목의 이름, 설명, 상징을 바꿀 수 있습니다. 편집을 누르면 순서를 바꿀 수 있습니다. 노트에서 좌우로 스와이프하거나 아래 화살표를 눌러 다음 항목을 확인하세요. 항목은 최소 한 개가 남아 있어야 합니다.

언어는 어떻게 바꾸나요?

설정 → 언어에서 지역 설정에 맞춤, 한국어 또는 English를 선택할 수 있습니다. 지역 설정에 맞춤은 iPhone의 지역 설정이 한국이면 한국어, 그 외에는 영어로 자동 표시합니다. 실제 위치나 GPS를 확인하는 기능이 아니며 위치 권한을 요청하지 않습니다.

직접 고른 언어는 다음 실행에도 유지됩니다. 언어를 변경해도 이미 작성한 pray나 항목 내용은 번역되거나 변경되지 않습니다.

오늘의 기도와 기도 기록은 어떻게 사용하나요?

노트 아래의 오늘의 기도를 눌러 pray를 읽어보세요. 마지막에 오늘 기도했어요를 누르면 그날의 기도 기록이 저장됩니다. 같은 날에 여러 번 기록해도 달력에는 하루로 표시됩니다.

상단의 나의 발자취 → 기도 기록에서 기도한 날에 표시된 점을 확인할 수 있습니다. 이 달력은 앱의 기록만 보여주며, iPhone 기본 캘린더의 일정을 읽거나 변경하지 않습니다.

응답된 pray와 달성일은 어떻게 기록하나요?

pray 옆의 동그라미를 눌러 달성일을 지정합니다. 응답된 pray는 원래 노트에 남으며, 나의 발자취에서 모아 볼 수 있습니다. 동그라미를 다시 누르면 달성일 수정, 달성 취소 또는 pray 삭제를 할 수 있습니다.

기도 알림을 켜고 싶어요.

설정 → 매일 기도 알림에서 알림을 켜고 원하는 시간을 선택한 뒤 저장하세요. 처음 사용할 때는 iOS 알림 권한을 허용해야 합니다. 선택한 시간에 기기에서 매일 알림을 예약하며, 개인적인 pray 내용은 알림에 표시되지 않습니다.

알림을 누르면 앱이 열리고 오늘의 기도 화면으로 연결됩니다. 알림을 여는 것만으로 기도 기록이 저장되지는 않습니다. 기도를 마친 뒤 오늘 기도했어요를 눌러주세요.

알림이 오지 않아요.

iPhone 설정 → 알림 → Praylist에서 알림이 허용되어 있는지 확인하고, 앱에서 알림 시간과 켜짐 상태를 다시 저장해 주세요. 집중 모드, 알림 요약, 소리 설정은 알림이 전달되는 방식에 영향을 줄 수 있습니다. 기기의 시간대가 바뀌면 현지 시간을 따릅니다. 알림을 사용하지 않아도 다른 기능은 사용할 수 있습니다.

새 기기로 기록을 옮기려면 어떻게 하나요?

기존 기기에서 설정 → 백업 파일 내보내기를 눌러 JSON 파일을 저장한 뒤, 새 기기에서 설정 → 백업에서 복원하기로 그 파일을 선택하세요. 복원은 현재 노트를 백업의 내용으로 교체하므로, 필요한 현재 기록은 먼저 내보내 주세요.

복원한 뒤에는 해당 기기에서 기도 알림을 다시 켜야 합니다. 언어 설정은 기기별로 유지됩니다. Praylist는 자체 서버를 통한 자동 동기화를 제공하지 않습니다.

백업 파일에는 pray와 기록이 포함되고 별도 암호가 설정되지 않습니다. 저장 위치와 공유 대상을 직접 선택하고 안전하게 보관해 주세요. iOS 설정에 따른 기기 백업은 수동 JSON 내보내기와 별개입니다.

기록을 삭제하려면 어떻게 하나요?

pray 옆의 동그라미를 누르면 해당 pray를 삭제할 수 있습니다. 설정 → 항목 관리에서 항목을 삭제하면 그 안에 담긴 pray도 삭제됩니다. 기기에 저장된 전체 앱 기록을 제거하려면 iPhone에서 앱을 삭제하세요.

별도로 내보낸 파일과 기기 백업은 앱을 삭제해도 남을 수 있으므로 해당 저장 위치에서 별도로 관리해야 합니다. 개발자는 기기에만 보관된 기록을 대신 복구할 수 없습니다.
