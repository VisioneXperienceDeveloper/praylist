# Praylist 개인정보 처리방침

시행일: 2026년 9월 11일  
운영자: VXDeveloper  
문의: visionexperiencedeveloper@gmail.com

Praylist는 나의 pray를 적고, 기도와 응답의 순간을 기록하는 앱입니다. 이 방침은 Praylist iPhone 앱의 개인정보 처리에 적용됩니다.

## 1. 앱에서 개인정보를 수집하거나 전송하지 않습니다

Praylist는 회원가입을 요구하지 않으며, 사용자가 작성한 pray와 기도 기록을 개발자 서버로 전송하지 않습니다. 광고, 이용 행태 분석 도구, 광고 추적 및 제3자 분석 SDK를 사용하지 않습니다. 개발자는 사용자의 기기에 저장된 노트를 열람할 수 없습니다.

## 2. 다음 정보는 사용자의 기기에 저장됩니다

- 항목의 이름, 설명, 상징과 순서
- pray의 내용, 저장된 메모, 생성일, 달성 여부와 달성일
- 기도한 날짜
- 알림 사용 여부와 알림 시간
- 앱 언어 설정

이 정보는 노트 표시, 내용 수정, 기도 기록, 알림 및 언어 설정 기능을 제공하기 위해 사용됩니다. 기도 기록의 달력은 앱에 저장된 날짜를 보여주며, iPhone의 캘린더 일정에 접근하지 않습니다.

## 3. 언어와 지역 설정

자동 언어를 사용할 때는 iPhone의 지역 설정이 한국이면 한국어, 그 외에는 영어를 표시합니다. 앱 설정에서 한국어 또는 영어를 직접 선택할 수 있습니다.

언어 선택을 위해 GPS나 실제 위치를 수집하지 않으며 위치 권한을 요청하지 않습니다. 지역 설정은 기기 안에서만 확인합니다. 언어를 바꾸어도 사용자가 작성한 pray와 항목 내용은 자동으로 번역되거나 변경되지 않습니다.

## 4. 기도 알림

사용자가 기도 알림을 켤 때만 iOS 알림 권한을 요청합니다. 알림은 선택한 시간에 기기에서 예약되며, 알림 내용에는 사용자가 작성한 pray를 포함하지 않습니다.

알림 권한은 iPhone 설정에서 언제든 변경할 수 있습니다. 알림을 허용하지 않아도 pray 작성과 기도 기록 등 다른 기능은 사용할 수 있습니다.

## 5. 백업과 복원

사용자가 백업 내보내기를 실행하면 항목, pray, 기도 기록 및 알림 설정을 포함한 JSON 파일을 만듭니다. 사용자는 파일의 저장 위치와 공유 대상을 직접 선택합니다. 언어 설정은 기기별 설정으로 관리됩니다.

백업 파일에는 개인적인 pray와 기록이 포함되며, Praylist는 내보낸 JSON 파일에 별도의 암호를 설정하지 않습니다. 보관하거나 공유할 때 주의해 주세요. 사용자가 iCloud Drive 등 외부 서비스에 저장하거나 다른 사람에게 공유한 파일에는 해당 서비스의 정책 및 사용자가 선택한 공유 설정이 적용됩니다.

Praylist는 자체 서버를 통한 자동 동기화를 제공하지 않습니다. 다만 사용자의 iPhone 백업 설정에 따라 앱 데이터가 Apple의 기기 백업 등에 포함될 수 있습니다.

## 6. 보관과 삭제

기록은 사용자가 삭제할 때까지 기기에 보관됩니다. 앱에서 pray 또는 항목을 삭제할 수 있으며, 앱을 삭제하면 해당 기기의 앱 저장 공간에 있는 기록도 삭제됩니다.

별도로 내보낸 파일이나 운영체제의 백업에 포함된 사본은 앱 삭제만으로 지워지지 않습니다. 해당 파일이나 백업이 저장된 위치에서 별도로 관리하거나 삭제해 주세요. 개발자는 기기에만 저장된 기록을 대신 복구하거나 삭제할 수 없습니다.

## 7. 문의할 때 제공하는 정보

사용자가 이메일로 문의하면 이메일 주소, 문의 내용 및 직접 첨부한 자료를 문의 응대에 사용합니다. pray나 백업 파일이 자동으로 첨부되지는 않습니다. 문의에 필요하지 않은 개인적인 pray나 민감한 정보는 보내지 않아도 됩니다.

문의 정보는 문의 해결과 필요한 후속 대응을 위해 보관하며, 더 이상 필요하지 않으면 삭제합니다. 관련 법령에 따라 보관이 필요한 경우에는 해당 기간 동안 보관할 수 있습니다. 이메일 서비스의 처리에는 해당 제공자의 정책이 적용됩니다.
