# Praylist UX 감사

## 범위

- 현재 체크아웃을 iPhone 17 Pro Simulator(iOS 27.0)에서 실행해 확인했다.
- 노트 작성, 달성일 기록, 오늘의 기도, 나의 발자취, 설정, 카테고리 관리, 알림 설정 화면을 살폈다.
- 사용자 인터뷰, 장기 사용 데이터, 전환율은 포함하지 않았다.

## 사용자 목표

사용자가 중요한 pray를 빠르게 적고, 매일 다시 읽고, 이루어진 날과 기도한 날을 부담 없이 남기는 것.

## 잘한 점

1. 빈 줄을 바로 편집할 수 있어 첫 행동이 설명 없이도 드러난다.
2. 오늘의 기도는 진행률과 단일 다음 행동만 남겨 집중을 잘 지킨다.
3. 달성일과 기도 달력이 기록을 회고로 연결해 제품의 의미를 만든다.
4. 주요 아이콘 버튼은 44pt 수준의 터치 영역과 접근성 레이블을 갖고 있다.
5. 설정은 알림, 카테고리, 언어, 백업, 도움말을 비교적 명확하게 묶는다.

## 못한 점

1. 한국어 모드에서 `Close`, `Edit`, `Done`, `Cancel`, `Save`가 남아 언어 일관성과 완성도를 깨뜨린다.
2. 메인 화면은 현재 위치만 `1/3`으로 보여주고 전체 카테고리 구조나 바로가기를 제공하지 않는다.
3. 자동 저장 시점이 키보드 완료 또는 포커스 이탈에 묶여 있지만, 저장 완료 상태나 즉시 실행 취소가 보이지 않는다.
4. 카테고리 관리의 설명문은 작은 글씨로 길게 배치되어 핵심 행동보다 먼저 읽히지 않는다.
5. 노트의 10칸 메타포는 매력적이지만 빈 공간이 크고, 항목과 pray가 많아질수록 순차 탐색 비용이 커진다.

## 접근성 위험과 한계

- 화면 캡처상 일부 보조 설명과 카테고리 관리 안내는 작고 밀도가 높다. 실제 Dynamic Type 확대와 줄바꿈은 별도 기기 테스트가 필요하다.
- 터치 대상과 접근성 레이블은 코드와 런타임 트리에서 확인했지만, VoiceOver 읽기 순서와 실제 음성 사용성은 이번 감사에서 검증하지 않았다.
- 색 대비는 화면상 뚜렷해 보이지만 수치 기반 WCAG 대비 측정과 저시력 환경 검증은 별도 작업이다.

## 우선순위

1. P0: 하드코딩된 영어 버튼 전부 현지화.
2. P1: 페이지 표시를 눌러 전체 카테고리 목록과 바로가기를 제공.
3. P1: 편집 직후 짧은 저장 완료 표시와 실행 취소 제공.
4. P2: 긴 설명을 첫 사용 힌트와 상황별 안내로 분리.
