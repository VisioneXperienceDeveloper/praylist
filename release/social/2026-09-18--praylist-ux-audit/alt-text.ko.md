# Instagram 대체 텍스트

1. 크림색 배경에 Praylist 앱 화면과 함께 “내 앱 UX, 내가 직접 깠습니다”라고 적힌 표지. 잘한 것 3개와 못한 것 3개를 다룬다고 안내한다.
2. “좋은 노트다. 아직 좋은 시스템은 아니다”라는 총평. 장점은 집중·감정·기록의 연결, 단점은 탐색·저장 확신·언어 일관성이라고 요약한다.
3. Praylist 메인 노트 화면과 “빈 줄이 곧 입력창이다”라는 평가. 첫 행동이 쉽고 별도 저장 화면이 없으며 10칸 구조가 상태를 보여준다고 설명한다.
4. 오늘의 기도 화면과 “기도할 때는 기도만 남긴다”라는 평가. 진행률, 한 방향 흐름, 부드러운 문장을 장점으로 꼽는다.
5. 달성일 입력 화면과 기도 기록 달력을 나란히 보여준다. 달성을 체크가 아닌 날짜로 남겨 기록에서 회고로 이어진다고 평가한다.
6. 한국어 설정, 나의 발자취, 카테고리 관리 화면의 상단을 보여주며 영어 Close와 Edit 버튼을 빨간 선으로 강조한다.
7. 메인 노트 화면과 “페이지 메타포가 정보 구조를 숨긴다”는 평가. 전체 카테고리 목록이 보이지 않고 원하는 항목으로 바로 갈 수 없다고 지적한다.
8. 노트 입력 영역과 자동 저장 방식을 설명한다. 키보드 완료나 포커스 이탈 때 저장되지만 저장 완료 표시와 실행 취소가 없다고 지적한다.
9. 개선 우선순위 네 가지. P0 언어 일관성, P1 카테고리 바로가기, P1 저장 확신, P2 안내문 다이어트 순서다.
10. Praylist 아이콘과 “예쁜 노트는 이미 됐다. 이제 길 잃지 않는 제품으로”라는 마무리 문구. 언어, 탐색, 저장 확신 중 무엇부터 고칠지 묻는다.
